# Portafolio de Ignacio Britos

Sitio estático (HTML, CSS y JS, sin build). Para verlo, abrí `index.html` en el navegador.

## Publicarlo en Vercel

Framework Preset: **Other**, sin Build Command ni Output Directory.

## Formulario de contacto

"Enviar propuesta" manda el mail de verdad con [FormSubmit](https://formsubmit.co), sin servidor propio.
La primera vez que alguien lo usa, FormSubmit manda un mail a britosignacio106@gmail.com con un botón
**Activate Form**: hay que tocarlo una sola vez y desde ahí los mensajes llegan directo.

## Estructura

- `index.html`: contenido (inicio, proyectos, caso de estudio, FreeWheel móvil, más proyectos, datos de GitHub, stack y contacto)
- `styles.css`: paleta, tipografías, bordes rectos, modo oscuro, modo lectura, colores para daltonismo y animaciones
- `main.js`: pantalla de carga, entradas al scrollear, tarjetas de proyectos, actividad de GitHub, formulario y el botón "No" que se escapa
- `assets/img/`: capturas de los proyectos

## Datos de GitHub

Los números están calculados a mano al 1 de noviembre de 2026, contando mis commits en todos mis repos
(públicos y privados). Para actualizarlos hay que cambiarlos en `index.html` y la actividad en `main.js`.
